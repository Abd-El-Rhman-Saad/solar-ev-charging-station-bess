# 📚 Project Documentation

This folder holds the written documentation of the **Solar-Powered EV Charging Station with BESS** graduation project.

## 📂 Contents

* **`Final Graduation Project Documentation - 2026.pdf`** — the complete thesis (287 pages). It covers:
  * PV array modeling (I-V / P-V characteristics) and the MPPT algorithms, including the Global MPPT for partial shading.
  * Component sizing and state-space averaging for the Interleaved Boost, Two-Quadrant Chopper and Buck converters.
  * Closed-loop control design and PI tuning (including the CC-CV charging logic).
  * Full-system simulation results and the hardware prototype validation.
* **`LaTeX_Source/`** — the LaTeX source of the thesis (`main.tex` and one file per section) and its figures.

## 🎤 Presentation
The final defense slides are published in the repository's [**Releases**](../../../releases/latest) section to keep the repository lightweight.

## 🎯 Purpose
Use the thesis as the reference for the *why* behind the Simulink models and the Altium boards in the other folders: design choices, equations, sizing calculations and measured results.
